# موجز إعادة تصميم واجهة ورد

## الهدف

إعادة بناء واجهة Android العربية لتستعير الوضوح البصري من الصور المرجعية: شريط علوي بنفسجي، تبويبات أفقية، بطاقات بيضاء مرتبة، لون تأكيد مرجاني، ومساحات بيضاء مريحة. يبقى المنتج تطبيق حفظ وتسميع القرآن، لذلك لا تكون شاشة المصحف هي نقطة البداية الوحيدة؛ تكون شاشة **الحفظ والتسميع** أول تبويب وأول إجراء واضح عند فتح التطبيق.

## هرم المعلومات

المهمة الأساسية هي بدء جلسة تسميع من الموضع الحالي. تأتي بعدها مباشرة حالة الهدف اليومي، ثم الموضع الحالي في المصحف، ثم الانتقال إلى المصحف والإعدادات والسجل. لا يتغير أي عقد في `QuranViewModel` أو `QuranRepository`؛ إعادة التصميم تعيد ترتيب العرض وتربط الأزرار بنفس callbacks الموجودة.

## نظام الألوان

| الدور | اللون | الاستخدام |
|---|---|---|
| بنفسجي رئيسي | `#673AB7` | الشريط العلوي، التبويب النشط، بطاقة الهوية |
| بنفسجي داكن | `#45238A` | شريط الحالة، الخلفيات العميقة |
| مرجاني | `#FF6F61` | مؤشر التبويب، زر الإجراء الأساسي، حالات التنبيه البصرية |
| خلفية فاتحة | `#F6F5F8` | خلفية القوائم |
| أبيض | `#FFFFFF` | البطاقات ومناطق القراءة |
| نص داكن | `#2B2438` | النص الأساسي والعناوين |

## أدوار الخط

يستخدم التطبيق خط النظام العربي المتاح على الجهاز دون شحن خط Quran-PNG أو أي خط مرجعي غير مرخص. العناوين كبيرة وذات وزن واضح، والنص القرآني يحافظ على حجمه واتجاهه العربي، بينما تستخدم التسميات الثانوية حجماً أصغر ولوناً أقل تبايناً.

## البنية المقترحة

```text
شريط الحالة بنفسجي داكن
┌──────────────────────────────────────┐
│  كتاب  ورد — حفظ وتسميع القرآن       │  شريط التطبيق
├──────────────────────────────────────┤
│  الحفظ        المصحف        السجل     │  تبويبات
├──────────────────────────────────────┤
│  وردك اليوم / التقدم / ابدأ التسميع  │  بطاقة البطل
│  جلسة التسميع الحالية                 │  الإجراء الرئيسي
│  الهدف اليومي                         │  التقدم
│  الموضع الحالي + فتح المصحف           │  سياق الحفظ
│  إعدادات التصحيح عند الحاجة           │  إعدادات ثانوية
└──────────────────────────────────────┘
```

## حالات الواجهة

تظهر الواجهة حالة التحميل بعبارة واضحة، وحالة عدم توفر Offline برسالة صريحة، وحالة الاستماع مع زر إيقاف، وحالة التصحيح الصوتي مع منع بدء جلسة مكررة، وحالة الهدف الفارغة بدعوة للبدء. لا توجد أزرار زخرفية بلا نتيجة؛ كل زر يعيد استخدام callback حقيقياً من ViewModel أو يغير التبويب محلياً.

## ما لا يتغير

لا تتغير بنية النص القرآني، أو محاذاة Reference، أو منطق التسميع، أو سياسة التصحيح، أو تقسيم الصفحات، أو وضع Online/Offline. لا تُستخدم صور الصفحات داخل التطبيق، ولا يُضاف ادعاء تطابق بصري بكسلي مع الصور المرجعية.

## معيار القبول

تبدأ الشاشة على تبويب «الحفظ»، يظهر زر «ابدأ التسميع» قبل عناصر المصحف الثانوية، وتبقى وظائف اختيار السورة، إخفاء الآيات، بدء وإيقاف الاستماع، التصحيح، الرجوع للآية السابقة، الهدف اليومي، المصحف، والسجل متاحة. يمر البناء والاختبارات وlint، ثم تُفحص الشاشة الرئيسية وتبويبات المصحف والسجل على الهاتف المتصل.
