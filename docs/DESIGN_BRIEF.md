# موجز تصميم وِرد — Quran Memorization Online

## الهدف

تحويل الشاشة الحالية إلى مساحة تسميع عربية هادئة وواضحة تساعد المستخدم على ثلاث خطوات أساسية: اختيار السورة، قراءة أو إخفاء النص، ثم بدء التسميع ومعرفة الكلمة الحالية والمشكلة. يجب أن تبقى حالة المحرك ومصدر الأصول مفهومة دون أن تنافس الآيات بصرياً.

## الجمهور والمهمة

الجمهور حافظ أو متعلم يريد ورداً قصيراً يومياً على هاتف Android. المهمة الأساسية هي بدء جلسة قصيرة بثقة، لا استعراض إعدادات تقنية. لذلك يظهر زر بدء التسميع كالإجراء الأساسي الوحيد، وتظل إعدادات المحرك والأصول في بطاقات ثانوية واضحة.

## الاتجاه البصري

الهوية البصرية: **حديقة هادئة للتسميع**؛ أخضر زمردي عميق يرمز للاستمرار، ذهبي دافئ يرمز للفعل الأساسي، وسطح عاجي خفيف يحافظ على راحة القراءة. التوقيع البصري هو بطاقة التسميع الداكنة ذات زر ذهبي كبير، مع بطاقة كلمة حالية خضراء فاتحة عند إخفاء النص.

يجب تجنب جدار بطاقات متساوية الوزن. ترتيب الانتباه هو: حالة الورد والسورة، النص أو حالة الإخفاء، بطاقة المحرك، زر التسميع، ثم الأصول والهدف والسجل. لا نضيف صوراً زخرفية غير لازمة؛ الصور المقصودة هنا هي لقطات التحقق والموارد المرئية المرقّمة.

## نظام التصميم

| الفئة | القاعدة |
|---|---|
| `QuranGreen` | `#2F806B` للأفعال الثانوية والحالات الجاهزة |
| `QuranGreenDark` | `#123F35` لبطاقة التسميع والعناوين العميقة |
| `QuranGold` | `#E4B96F` لزر الإجراء الأساسي |
| `QuranSurface` | `#FFFFFF` للبطاقات |
| `QuranBackground` | `#F5F7F2` لخلفية القراءة |
| `QuranMuted` | `#64736B` للشرح والحالات الثانوية |
| نصف القطر | 18dp للبطاقات العادية، 24dp للبطاقات الرئيسية |
| الحشو | 16–20dp داخلياً، وفاصل 12–16dp بين الأقسام |
| اللمس | 48dp على الأقل لكل زر أو شريحة |
| النص القرآني | حجم كبير، RTL، تباعد مريح، بلا قص أفقي |
| النص الوظيفي | عناوين قصيرة ورسائل عربية مباشرة |

## حالات يجب أن تظهر بصدق

تشمل الواجهة التحميل، جاهزية الأصول، فشل الشبكة، Online، Offline والنموذج غير الجاهز، تنزيل النموذج، Stream، Download، إخفاء النص، الاستماع، الصمت المرحلي، النتيجة الجزئية، النتيجة النهائية، الكلمة المفقودة، الكلمة الزائدة، الإيقاف اليدوي، والسجل الفارغ. لا تعرض الواجهة أن الجلسة انتهت عند `onEndOfSpeech` أو صمت قصير؛ النهاية المرئية تكون فقط عند الإيقاف اليدوي أو خطأ غير قابل للاسترداد.


## معايير القبول

تكون الشاشة الأولى مفهومة خلال ثوانٍ، ويُميّز المستخدم بين تبويب «التسميع» وزر «ابدأ التسميع». في وضع الإخفاء لا يظهر النص الكامل، وأثناء الاستماع تظهر آخر كلمة مرصودة في بطاقة مستقلة. لا يختفي زر الإيقاف عند الصمت، ولا يحدث قص للنص العربي على شاشة 720×1600. يجب اختبار الحالات الأساسية بلقطات الأسماء أعلاه، مع ذكر ما لم يُختبر.
