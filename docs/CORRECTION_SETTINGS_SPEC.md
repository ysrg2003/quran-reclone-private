# عقد إعدادات تصحيح الشيخ

## الهدف

تسمح بطاقة **سياسة تصحيح الشيخ** للمستخدم بتعديل دورة التصحيح الصوتي من داخل التطبيق، مع حفظ الاختيارات محلياً على الجهاز. لا تغيّر هذه الإعدادات نص القرآن المعروض أو قاعدة المطابقة العربية، ولا تجعل التطبيق مصحح تجويد؛ هي تضبط متى وكيف يُشغّل مقطع المرجع بعد حدث تصحيح نصي.

## الافتراضات الافتراضية الحالية

عند أول تشغيل، أو بعد ضغط زر **الافتراضي**، تكون السياسة كما يلي:

| الإعداد | الافتراضي الحالي | النتيجة |
|---|---:|---|
| التصحيح التلقائي | مفعّل | يبدأ المرجع تلقائياً بعد نتيجة مستقرة فيها خطأ |
| تصحيح الكلمة الخاطئة | مفعّل | يصحح الخطأ في الموضع المتوقع |
| تصحيح الكلمات المتخطاة | مفعّل | يصحح أول كلمة متروكة عند مطابقة كلمة لاحقة |
| تصحيح القفز بين الآيات | مفعّل | يثبت الآية المتوقعة ولا يتبع الآية التي قفز إليها القارئ |
| الرجوع التلقائي إلى الآية السابقة | مفعّل | عند تأكيد أول كلمتين من الآية السابقة في بداية الآية الحالية، يرجع إليها ويبدأ منها دون ضغط |
| عتبة الآية الكاملة | 3 أخطاء متتالية | كلمة فقط قبل العتبة، ومقطع أول خطأ ثم الآية كاملة عند بلوغها |
| مقطع أول خطأ قبل الآية | مفعّل | الترتيب: مقطع أول خطأ ثم الآية المرجعية كاملة |
| تكرار مقطع الكلمة | مرة واحدة | لا يتكرر المقطع تلقائياً |
| تكرار الآية الكاملة | مرة واحدة | لا تتكرر الآية تلقائياً |
| الفاصل بين المقاطع | فوري | لا يوجد انتظار إضافي بين المقطع والآية |
| هامش المقطع قبل/بعد | 0 مللي ثانية | يستخدم توقيت الكلمة كما يأتي من مصدر التوقيتات |
| موضع الاستئناف | أول خطأ | يقبل المتعقب بدءاً من موضع الخطأ مع نافذة الرجوع داخل الآية |

## الخيارات التي يتحكم بها المستخدم

يمكن تعطيل التصحيح التلقائي كله أو تعطيل نوع محدد منه مع بقاء التقييم النصي والألوان فعالين. ويمكن تعطيل الرجوع التلقائي إلى الآية السابقة إذا أراد القارئ أن يُعامل تكرارها كتلاوة غير متوقعة. ويمكن تغيير العتبة بين 1 و6 أخطاء متتالية، وتحديد تكرار مقطع الكلمة والآية الكاملة بين مرة وثلاث مرات، واختيار فاصل 0 أو 250 أو 500 أو 1000 مللي ثانية. كما يمكن إضافة هامش قبل المقطع أو بعده بقيم 0 أو 80 أو 150 أو 300 مللي ثانية ضمن حدود التسجيل المرجعي.

عند اختيار **الآية كاملة** مع تفعيل «مقطع أول خطأ قبل الآية»، يشغّل المشغل مقطع الكلمة أولاً ثم الآية كاملة. عند إلغاء ذلك الخيار، يشغّل الآية كاملة وحدها. في طلب تصحيح الكلمة المفردة أو سلسلة أقل من العتبة، لا تُضاف الآية كاملة إلى الطابور.

يحدد خيار الاستئناف نقطة الارتكاز الصوتية والمنطقية بعد انتهاء المرجع: **أول الآية**، أو **أول خطأ**، أو **الكلمة التالية للخطأ**. لا يلغي هذا الاختيار قبول القارئ لكلمة صحيحة قبل موضع الخطأ داخل الآية؛ المتعقب يحتفظ بنافذة الرجوع ويمنع البحث الحر في بقية القرآن. أما الرجوع التلقائي فليس زر تصحيح ولا يحتاج تدخلاً؛ يتطلب تأكيد كلمتين متتاليتين من بداية الآية السابقة، ويتجنب الرجوع إذا طابقت الكلمة الأولى بداية الآية الحالية نفسها لتقليل الالتباس بين الآيات المتشابهة.

## الحفظ وإعادة الضبط

تُحفظ الإعدادات في `SharedPreferences` محلياً تحت مساحة التطبيق، ولا تُرسل إلى خادم أو مزود SpeechRecognizer. زر **الافتراضي** يمسح الاختيارات المحفوظة ويعيد قيم العقد أعلاه. ويضمّن تصدير النسخة الاحتياطية نسخة الإعدادات الحالية بجانب سجل الجلسات والهدف اليومي.

## الحدود

تعمل العتبة على الكلمات التي تثبت في نتيجة نهائية أو نهاية مقطع مستقر. لا يبدأ التصحيح من `partial` غير مستقر. إذا كان مزود `SpeechRecognizer` يجزئ سلسلة الأخطاء إلى نتائج نهائية منفصلة فقد تختلف لحظة اتخاذ القرار عن نتيجة واحدة تحتوي الكلمات كلها؛ لذلك يبقى اختبار الصوت على الجهاز الفعلي مطلوباً، ولا تعني الإعدادات ضمان فهم كل لهجة أو تصحيح التجويد.
